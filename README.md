# Dados-Sinais-PEC
Repositório dedicado a armazenar dados Sinais PEC (Pulsed Eddy Currents) de tubulações metálicas com 3 classes: Sem Defeito, Defeito Interno e Defeito Externo

Esses dados foram utilizados na pesquisa de doutorado do Doutor Manoel Messias Silva Junior - UFOB e no trabalho de conclusão de curso de Matheus Pereira Alves.

Agradecimentos dedicados à Manoel e ao laboratório de instrumentação da UFBA.
